# Roteiro apresentação

### Sobre o projeto
O objetivo do presente projeto é testar e comparar a utilização de dois algoritmos de aprendizagem de maquina, ambos os algoritmos supervisionados, sendo eles KNN e DecisionTree.
Para a implementação de tal projeto a linguagem utilziada foi o python em em sua versão 3, mais especificamente 3.14 com o ambiente virtual venv. Para utilização dos algoritmos, criação de graficos e operações com matrizes foram utilizadas, bibliotecas externas, sendo elas: Numpy, Pandas, Matplotlib, Seaborn e Scikit Learn.
O projeto foi dividido em etapas onde cada etapa é feito um procedimento dentro do contexto de comparação de dois algoritmos.
